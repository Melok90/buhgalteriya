# Мобильное приложение «Бухгалтерия» (React Native + Expo)

Полноценная нативная мобильная версия приложения расходов и доходов, построенная по стандартам Apple Human Interface Guidelines (Dark Mode).

---

## Возможности приложения
- **Карточка баланса**: доступный остаток с динамической подсветкой, расходы за месяц, средний расход в день и кнопка аналитики.
- **Компактные фильтры категорий**: быстрый отбор по 8 категориям («Все», «Еда», «Транспорт», «Жилье», «Покупки», «Здоровье», «Кафе», «Развлечения», «Другое»).
- **Изолированный список операций**: скроллится только список транзакций, карточка баланса и шапка зафиксированы.
- **Круглые цветные бейджи 36px**: сочные акцентные цвета категорий и четкие векторные иконки.
- **Шторка добавления операции**:
  - Центрированные кнопки-переключатели **[− Расход]** и **[+ Пополнение]** с круглыми цветными бейджами.
  - Кнопка закрытия `✕` строго в верхнем правом углу.
  - Крупный дисплей ввода суммы (48px) с поддержкой копеек.
  - Интерактивная карточка выбранной категории с тратами за сегодня (`Сегодня · X ₽`).
  - Поле комментария с префиксом `+`.
  - Калькуляторная клавиатура 3×4 (`1`–`9`, `.`, `0`, `⌫`) с нативным виброоткликом Taptic Engine (`expo-haptics`).
  - Главная кнопка действия во всю ширину: `Добавить расход · X ₽` / `Пополнить · X ₽`.
- **Модальный выбор категории**: список с подсветкой активной категории галочкой `✓`.
- **Аналитика трат**: сводка показателей и прогресс-бары распределения расходов.
- **Персистентное хранение**: все операции сохраняются локально через `@react-native-async-storage/async-storage`.

## Быстрый старт

### 1. Установка зависимостей
Откройте терминал и выполните:
```bash
cd mobile
npm install
```

---

### 2. Запуск на реальном телефоне (iPhone или Android) за 2 минуты (без Xcode!)
1. Установите бесплатное приложение **Expo Go** из App Store (на iPhone) или Google Play (на Android).
2. В папке `mobile` запустите:
   ```bash
   npm start
   ```
3. Откройте камеру на iPhone (или Expo Go на Android) и наведите на появившийся в терминале QR-код.
4. Нажмите «Открыть в Expo Go».

---

### 3. Запуск в симуляторе iOS на Mac

> [!NOTE]
> Симулятор iOS входит в состав **Xcode**. Если Xcode еще не установлен:
> 1. Установите **Xcode** из Mac App Store.
> 2. Откройте Xcode один раз для установки базовых компонентов симулятора.
> 3. Переключите консоль на Xcode:
>    ```bash
>    sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
>    ```

После этого:
1. В папке `mobile` выполните:
   ```bash
   npm run ios
   # или запустите `npm start` и нажмите клавишу `i`
   ```
2. Expo автоматически запустит iOS Simulator (например, iPhone 15 Pro) и откроет приложение.
